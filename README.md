## What is Invva?

Invva is an open-source inventory management system designed for small retail shops, online sellers, and small manufacturers. Track products, manage stock, and stay organized—without complexity.

### Planned Features

- ✅ Simple Product Management
- ✅ Stock Tracking  
- ✅ Barcode Scanning
- ✅ Real-time Updates
- ✅ Mobile-First Design
- ✅ Open Source

---

## Technology Stack

- **Frontend:** Next.js 14, React, Material UI, Tailwind CSS
- **Backend:** Next.js API Routes
- **Database:** PostgreSQL + Prisma ORM
- **Auth:** Email verification
- **Deployment:** Vercel, Railway, AWS, or self-hosted
